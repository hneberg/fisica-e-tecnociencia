🤖

05 — PROGRAMANDO O ROBÔ

O código transforma informação em ação.

Um dos princípios fundamentais da programação de robôs é utilizar condições para decidir o que deve acontecer.

robot.js 
const luz = sensorOptico();

if (luz < 30) {

    robo.acenderLED();
    robo.parar();

} else {

    robo.avancar();

}
